# Тихо

Спокойный todo-list на Astro и TypeScript. Тёплая бумажная палитра, заголовки с засечками, терракотовый акцент. Работает без аккаунта и API.

## Запуск

Node.js версии, поддерживаемой установленным Astro (проверено на Node 26).

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:4321 на машине, где запущен сервер. Сервер по умолчанию слушает только localhost. Публичная версия: https://tyrtyshnyy.github.io/todo-hermes-ai/. В GitHub Actions сборка использует базовый путь `/todo-hermes-ai/`, локально — `/`.

```sh
npm run check
npm test
npm run test:e2e
npm run build
npm run preview
```

Для браузерных тестов на новой машине установите Chromium: `npx playwright install chromium`. На минимальном Linux также нужны системные библиотеки Chromium и fontconfig со шрифтами. Конфигурация автоматически использует локальную среду из `.cache/`, если она присутствует; этот каталог не входит в Git.

## Возможности

- Создание, редактирование, выполнение, возврат и удаление задач; отмена последнего удаления до скрытия уведомления или перезагрузки.
- Три проекта: Работа, Личное, Идеи; приоритеты и сроки.
- Все активные, сегодня (включая просроченные), предстоящие, завершённые.
- Поиск по названию, фильтр важных задач, сортировка по добавлению, приоритету и сроку.
- Светлая/тёмная тема; адаптивная боковая панель.
- Горячие клавиши: N/Т — новая задача, / — поиск, Escape — закрыть окно/меню.
- Пустой список по умолчанию; примеры загружаются только по кнопке.

## Данные и ограничения

Задачи находятся только в localStorage текущего браузера (`tikho.tasks.v1`). Нет облака, синхронизации между устройствами, авторизации, уведомлений, AI-интеграции и резервного копирования. Очистка данных сайта удалит задачи. Не храните единственную копию критичных данных здесь.

Сохранённые данные проверяются перед загрузкой. Повреждённые данные не перезаписываются: интерфейс сообщает об ошибке и работает в памяти до перезагрузки. При отказе записи появляется предупреждение. Одновременное редактирование в нескольких вкладках не синхронизируется — последнее сохранение побеждает.

Шрифт Golos Text загружается через Google Fonts; без сети используются Arial и Georgia/системные замены. Остальной интерфейс не требует внешних API после загрузки страницы.

## Структура

- `src/pages/index.astro` — разметка приложения и диалога.
- `src/styles/global.css` — токены, темы, адаптивные стили.
- `src/scripts/app.ts` — взаимодействия и сохранение.
- `src/lib/state.ts` — создание, валидация и фильтрация задач.
- `tests/state.test.ts` — тесты модели.
- `tests/e2e/` — реальные браузерные сценарии и снимки desktop/mobile/dark.

Сборка статическая: результат в `dist/`. Сайт публикуется из ветки `gh-pages` (корень `/`). Для сборки Pages выполните `GITHUB_ACTIONS=true npm run build`, затем опубликуйте содержимое `dist/` в ветке `gh-pages` с файлом `.nojekyll`. Автодеплой из `main` пока не включён: текущий OAuth-токен не имеет права `workflow`. Шаблон Actions сохранён в `.github/pages-workflow.example.yml`; после предоставления права его можно перенести в `.github/workflows/pages.yml` и переключить источник Pages на GitHub Actions.
